## Edge به کجا رسید؟

**NOT_ESTABLISHED**. برای سه خانوادهٔ فعلی baseline واجد شرایطِ پس از هزینه اجرا نشده؛
نتیجهٔ بهینه‌سازی معتبر و holdout دست‌نخورده نیز اثبات نشده‌اند. دو مانع مستقل baseline:

1. دادهٔ مشاهده‌شده و هم‌زمان `5m OBI/CVD` و `1m quotes` واجد شرایط موجود نیست؛
   default یا proxy جای مشاهدهٔ واقعی نیست.
2. مدل پشتیبانی‌شده و صادقانه برای `POST_ONLY/LIMIT` maker وجود ندارد؛ guard جدید
   به‌جای ساختن fill غیرواقعی آن مسیر را رد می‌کند.

اصلاح ساعت‌های replay، training-only WFO، هویت نماد و نبود متریک ساختگی، صحت ارزیابی
را بهتر کرده‌اند؛ سودآوری را ثابت نکرده‌اند. آخرین مجموعهٔ انتخابی ثبت‌شدهٔ main
`314 PASS / 27 warnings` و آزمون launcherِ primary برابر `13 PASS` است؛ هر دو تاریخی،
بدون استقرار و بدون ادعای مرور مستقل برای آخرین patchها. امروز تست کد تکرار نشد.

مسیر Edge: صلاحیت منبع و lineage → تعریف دقیق یک فرضیه/پلن و مدل هزینه/اجرا و
تقسیم داده پیش از دیدن نتیجه → baseline پس از هزینه → بهینه‌سازی فقط train →
WFO/OOS و بررسی عدم‌قطعیت/تمرکز → گیت prospective مربوطه → تصمیم ارتقا.
مطالعهٔ جزءِ کاهش‌یافته روی C06 می‌تواند فقط پس از قرارداد علمی صریحِ DEVELOPMENT_ONLY
بررسی شود؛ همان baseline کامل یا شاهد مستقل Edge نخواهد بود.
