## Question and source semantics

On a genuinely later BTCUSDT/ETHUSDT 1h public Binance USD-M Futures interval, does **pre-existing Lynxion structural bias agreeing with an independently generated Engine directional proposal** identify a subset with greater next-completed-hour side-adjusted close-to-close return than comparable nonagreeing directional proposals? This is a Level-1 predictive **conditional-selection** estimand, not an ExecutionIntent, fill, portfolio result or economic Edge.

Direction is actual `TrendMTFWatcher` → `EngineService.process_observation` BUY/SELL using unchanged rolling 5/15/30 **same-timeframe** closes and existing Engine mapping. It is reused for a new incremental-condition question, not repaired or retuned after V1. It has no true multi-timeframe input despite its name. Structural state is actual `MarketStructureEngine.calculate_market_structure` with its unchanged 20-close, close-price/volume-bin proxy and built-in LONG/SHORT/NEUTRAL POC buffer (0.1% of current close). The **only** eligibility rule is BUY+LONG or SELL+SHORT at the same completed 1h bar. BUY+SHORT, SELL+LONG and either side+NEUTRAL are controls. This conjunction is research-only; no production rule is added. Both source implementations predate V1 outcome inspection (`c5a3b3c` or earlier). Exclude any event if either source output is missing/invalid; report all missingness. No OBI/CVD/BBO, synthetic quote, Strategy, SetupEngine, Fusion, Risk or broker state enters this test.

## Primary outcome and comparability

Primary label is **one later completed 1h close** of the same symbol: side-adjusted simple gross return, BUY `(close[T+1]-close[T])/close[T]`, SELL the negative. The next completed bar is the first observation interval after the 1h structural state is known. This is a **pre-outcome scientific horizon choice**, not a source-defined holding period or executable exit; it deliberately does not copy V1's four-hour horizon. An event without a later close **inside the frozen acquisition interval** is censored, not assigned zero. Report full, excluded, censored, eligible and control counts.

Comparable strata are **symbol × ISO UTC week × proposal side (BUY or SELL)**. Keep only strata with at least one eligible and one control after causal/censor exclusions. Do not select controls based on later returns, nearest profitable timing or a future-defined market state. The primary contrast is the coefficient of eligibility in a within-stratum mean-difference estimator: for each stratum, eligible mean minus control mean, weighted by `n_eligible*n_control/(n_eligible+n_control)` and divided by the sum of those weights. This is equivalent to a pooled linear model with stratum fixed effects, giving each directional opportunity one observation while preventing symbol/week/side mix from defining the effect. No outcome-based subset or alternative matching is permitted.

This is a deliberately high *predictive materiality* hurdle, **not** a fee estimate or trading threshold. These SD/dependence values are planning assumptions, **not observed V1 outcomes or a power guarantee**.
