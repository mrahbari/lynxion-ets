# Replay correlation event-time contract

Start HEAD `b153285`. This unit adds a replay-local scheduler over the **same** `EnterpriseRiskManager.recalculate_correlations()` method. Live construction still starts the existing daemon worker with the same approximately ten-second sleep. Explicit replay construction passes `start_correlation_worker=False`; it starts no thread.

Replay initializes `ReplayClock` at a caller-specified UTC start `T0`. The first due calculation is `T0 + 10 seconds`, then nominal ten-second boundaries. This phase is a **replay-only deterministic initialization rule**. Live's actual worker start/wake times were not archived and are not claimed to match it. When advancing to event time `T`, all due boundaries **strictly before T** are processed with prior causal price history and the clock advanced to each boundary. Then all causal price updates for `T` are recorded as one complete batch. A publication due **at T** runs after that batch and before a same-time Risk evaluation. Separate batches with the same timestamp are rejected to prevent accidental partial same-time publication.

No correlation calculation occurs just because an order arrives or a candle arrives. No future price at `T` is visible to a prior boundary. Empty intervals are explicitly processed using the unchanged function; it is idempotent in matrix values, though each successful publication has a new snapshot version. The scheduler does not use `sleep`, wall time, a worker thread, or network access. Two replay managers/schedulers have separate matrices, histories and publication traces.

Focused tests cover repeated traces, gaps, same-time ordering, monotonic timestamp rejection, boundary clock positions, no thread/sleep and two independent scopes. Expanded applicable regression: **131 passed / 0 failed**. Protected persistence hashes matched before/after. This is deterministic publication/consumption semantics for a **defined replay runtime**, not reconstruction of historical Live worker timing. `HISTORICAL_CORRELATION_SCHEDULE_NOT_RECONSTRUCTABLE` remains. Full ApplicationRunScope, canonical historical wiring, prefix invariance and live/replay decision parity are not yet proven.
