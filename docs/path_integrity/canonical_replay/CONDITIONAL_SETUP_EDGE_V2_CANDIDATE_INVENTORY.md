## Direction source and rationale

For this structural-state family the outcome-blind lowest-burden direction source is the existing `TrendMTFWatcher` → `EngineService` BUY/SELL proposal already proven to use completed 1h closes, with deterministic isolated state. This is *not* chosen because V1 lost or because a V1 residual appeared favorable. A separate `AnomalyMLWatcher` direction mixes momentum spikes and contrarian anomaly mapping and still has unresolved event-time/forensic isolation; it is not required to test the structural-state question. Reusing TrendMTF here means V2 could test **incremental structural eligibility**, never a repaired V1 or a new directional rule. Watcher weights/windows, Engine thresholds and V1 records remain unchanged.

The conjunction “Engine side agrees with structural bias” is a **new study eligibility contract combining two pre-existing outputs**. It has not been added to production strategy logic. Controls are the same-source directional opportunities not meeting that agreement. For a prospective comparison using **all** directional hourly proposals (rather than V1's 4h thinning), the old archive has 417 proposals: 291 agreement and 126 nonagreement. Symbol×ISO-week×side comparability retains 16 strata with both arms, 266 agreement and all 126 nonagreement events over 25 UTC days. These are still only old-archive feature counts, not outcome evidence. A future preregistration must freeze matching, horizon, missingness, sample/power and clustering before any V2 outcome. Controls are materially fewer and clustered, so an unseen window must be qualified for sample/power. This document neither freezes a V2 test nor authorizes opening labels.
