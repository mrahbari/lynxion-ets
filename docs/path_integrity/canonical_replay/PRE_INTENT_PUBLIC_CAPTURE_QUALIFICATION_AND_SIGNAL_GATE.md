## Frozen sample gate fails before outcomes

All 1,340 evaluation `FusedSignal` outputs (670 per symbol) have `dominant_bias=NEUTRAL`; directional BUY/SELL events = **0**. The frozen study requires at least 100 non-overlapping eligible primary directional events and 20 distinct UTC days per symbol. Both cannot be met. No forward close, return, PnL, expectancy, bootstrap, cost estimate, or other study outcome was calculated. This is **not** evidence of absent predictive Edge; the preregistered estimand has no eligible directional sample in this composition.

The first source-supported reason is a Watcher/Engine observation-type contract mismatch: the historical watcher emits `candle_reversal_bullish_emerging` / `candle_reversal_bearish_emerging` on the evaluated path; `EngineService._determine_signal_type` has no candle-reversal branch and returns NEUTRAL for unknown types; the current single-input Fusion path copies the interpreted signal type into `dominant_bias`. A preliminary stage count found 724 bullish-emerging and 616 bearish-emerging observations, all interpreted NEUTRAL. This is a decision-semantic issue, **not** a data-acquisition defect. Mapping those types to BUY/SELL, switching watchers, or changing the frozen estimand would change study/trading semantics and is not authorized by the data-only addendum. No such change was made.

Decision: `PRE_INTENT_EDGE_MEASUREMENT_NOT_READY`; frozen study **not activated**. Smallest remaining blocker: an explicitly reviewed, pre-outcome decision on the historical-watcher/Engine semantic mismatch or a separately preregistered question/cohort. Do not treat the structurally qualified candle archive as permission to run the current study. Full Strategy/ExecutionIntent OBI/CVD/BBO provenance, SetupEngine event time, XMR cause and broker retry remain parked.
