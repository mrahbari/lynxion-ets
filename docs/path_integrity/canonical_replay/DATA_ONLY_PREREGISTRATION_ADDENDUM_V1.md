## One source and exact windows (UTC)

Source: Binance USDⓈ-M Futures public symbol Kline/Candlestick Data, `GET https://fapi.binance.com/fapi/v1/klines`; `symbol=BTCUSDT` and `symbol=ETHUSDT`, `interval=1h`, one identical request interval per symbol, `limit=1500`, no authentication. Binance's [official endpoint specification](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data) identifies row `[0]` as open time in milliseconds, `[6]` as close time in milliseconds, and `[1:6]` as OHLCV. Preserve both exchange times. The causal availability instant is the **next UTC hour boundary**, verified as `close_time_ms + 1` and `open_time_ms + 3_600_000`; no complete bar is visible earlier. Reject a row if this relation, alignment, source schema, or completed status is false. Do not confuse API retrieval time with historical availability time.

- **Acquisition window** (bar open times): `[2026-05-31 00:00, 2026-07-02 00:00)` UTC. Request both symbols over this exact window; API `endTime` is the final millisecond before the exclusive end. Expected 768 hourly rows per symbol if complete. No rolling/latest-data request.
- **Outside-evaluation leading margin:** `[2026-05-31 00:00, 2026-06-01 00:00)` UTC, 24 bars for boundary/source validation only.
- **Warmup:** `[2026-06-01 00:00, 2026-06-03 02:00)` UTC, exactly 50 completed 1h bars per symbol for watcher state. No warmup signal is an eligible study event.
- **Evaluation window:** `[2026-06-03 02:00, 2026-07-01 00:00)` UTC by bar open time, expected 670 hourly bars per symbol if complete. It is selected by a fixed UTC calendar rule before outcomes, not by observed market behavior. Only signals attached to these bars may enter the frozen study. No later expansion based on neighboring data.
- **Outside-evaluation trailing margin:** `[2026-07-01 00:00, 2026-07-02 00:00)` UTC, 24 bars used only for boundary verification and up to four-bar outcome completion for eligible evaluation signals. These margin bars never create new eligible signal events.

The acquisition interval is 32 days and the evaluation interval is 27 days 22 hours. The original preregistration's common-window requirement remains: both symbols must be complete over the **same** warmup/evaluation interval, with >=20 distinct UTC days per symbol represented by eligible observations and >=100 non-overlapping eligible primary events in total. These event minima are not guaranteed by row count; count only after the qualified pre-intent path runs. Duplicate, gap, invalid/nonfinite OHLCV, negative volume, non-monotonic or misaligned exchange timestamps cause qualification failure; no bfill, resample, proxy or silent repair.

## Capture, normalization and immutable manifest

Capture each public HTTP response body as **raw bytes** at a new versioned path `data/research/pre_intent/candle_capture_v1/raw/{symbol}/page-0001.json`, never overwrite the old processed files. Record response SHA-256, UTC request/receipt times, exact URL parameters, HTTP status, source documentation URL, response row count and first/last exchange open/close times. Do not store secrets. If pagination is unexpectedly required, record each page and cursor; no missing pages or source mixing. No private/account/order endpoint may be called.

Immediately create an immutable capture manifest with parent preregistration hash, **this addendum hash and commit**, acquisition/evaluation/margin boundaries, source/API identity, file paths/hashes/sizes, row counts, timestamp units/semantics, provenance and capture times. A normalized closed-bar artifact may be created only from these raw files, with OHLCV and both raw exchange timestamps retained and a derived completed availability instant. Hash normalized files and append quality/qualification results in a separate manifest version. Raw bytes must remain unchanged. The eventual study pins a qualified manifest hash, not a folder.

Only after raw capture, provenance, common coverage, all quality gates, multi-cut real-archive prefix invariance and repeated-run determinism pass may the frozen study run. Additional acquired observations are not automatically evaluation observations. No Strategy/ExecutionIntent, order, broker or production persistence is part of this addendum.
