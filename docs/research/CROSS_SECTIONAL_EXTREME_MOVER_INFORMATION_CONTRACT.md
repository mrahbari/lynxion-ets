# Extreme-mover information contract — design only

2026-10-05. R22 remains `INDEPENDENT_LEAD / NOT_YET_TESTED`; [data feasibility](CROSS_SECTIONAL_EXTREME_MOVER_FEASIBILITY.md) is `EXTREME_MOVER_DATA_PARTIAL`. This is an **outcome-blind measurement contract**, not an activated collector, V3 hypothesis, inclusion rule or preregistration. Venue, cadence, ranking formula, thresholds, holding horizon and sample floor are **UNDECIDED**.

At a hypothetical decision instant **T**, a field may be used only if its entire source interval ended and the payload was received and durably recorded no later than T. Exchange event time alone does not prove local availability. For each raw payload retain source URL/feed, request parameters, exchange timestamp if supplied, local send/receive UTC and monotonic timestamps, raw bytes/hash, retrieval status and immutable file identity. A missing payload is `UNAVAILABLE`, never zero or a favorable default.

| Field / proposed role | Provenance class | Time-T availability and failure rule |
|---|---|---|
| Contract universe, type, quote/margin asset, trading status, onboard/delivery dates | `OBSERVED` current venue metadata; historical state `UNAVAILABLE` unless captured then | Use only a contemporaneously received full exchange-info snapshot. Preserve additions, removals and status changes; never derive past membership from today's list. |
| Venue-normalized symbol/contract identity | `DERIVED_FROM_OBSERVED` metadata | Maintain raw venue symbol and explicit mapping version; unresolved mapping excludes the contract from comparable cross-venue claims, not silently remapped. |
| Closed-bar open/high/low/close, base/quote volume, trades, taker-buy fields | `OBSERVED` exchange aggregates | Eligible only after bar close **and receipt**. Incomplete/missing bar or uncertain timestamp excludes the symbol-slot from a complete rank denominator. Exchange-aggregated flow is not price-level microstructure. |
| Price change, relative rank, top/bottom membership, turnover or participation acceleration | `DERIVED_FROM_OBSERVED` | Compute only from eligible same-cutoff completed bars and a frozen contemporaneous universe. Formula and comparison window must be frozen before activation; no ranked list is generated by this document. |
| Consolidation / first-pullback state | `DERIVED_FROM_OBSERVED` if a later causal formula exists; presently `UNAVAILABLE` as a defined research feature | Future setup definition must use prior completed bars only. No retrospective drawing of a successful pattern or bfill. |
| BBO, spread, depth/market quality | `OBSERVED` only from contemporaneous raw quote/book feed; otherwise `UNAVAILABLE` | Archive a received quote at/before T with source timestamp and staleness bound frozen later. Turnover is at most a `PROXY` for liquidity, never observed spread. |
| Fee schedule, funding and executable fill/slippage | Fee/funding could be `OBSERVED` if time-valid source retained; executable fill presently `UNAVAILABLE` | A candle close is not a fill. Future economic test needs its own pre-outcome executable pricing and cost contract. |

No `SYNTHETIC` or `DEFAULT/FALLBACK` field may enter an observed-information claim. Missing universe snapshots, status transitions, bars or quotes must produce explicit missingness and denominator changes, not a repaired panel. The all-symbol sampling/receipt schedule, exclusion logic, listing/delisting audit, acquisition budget, independent-day floor and untouched evaluation boundary must be fixed **before** any prospective capture intended for inference. Capture alone would not authorize inspecting future returns or treating collected data as confirmatory.
