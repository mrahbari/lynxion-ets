# 1. EXECUTIVE VERDICT

### **PROVEN SOURCE-CODE MECHANISM: DEFAULT DEMO CONSTRUCTOR CAP OF $50,000–$100,000 VST**

This forensic audit identifies the exact source-code mechanism that permitted $30,000–$100,000 notional trades during trades 301–500:

1. **Exact Source-Code Mechanism**:
   - `EnterpriseRiskManager.__init__()` ([`application/risk_management/enterprise_risk_manager.py:39-40`](file:///Users/mojtaba.rahbari/Sites/python/lynxion-ets/application/risk_management/enterprise_risk_manager.py#L39-L40)) hardcoded default constructor parameters:
     - `max_portfolio_exposure: float = 100000` ($100,000 VST)
     - `max_position_exposure: float = 50000` ($50,000 VST)
   - When risk configuration was uninitialized or defaulted during demo initialization, `validate_position_entry()` validated order notionals against these $50,000–$100,000 caps.
2. **Sizing Formula Amplification**:
   - `calculate_position_size()` ([`L187`](file:///Users/mojtaba.rahbari/Sites/python/lynxion-ets/application/risk_management/enterprise_risk_manager.py#L187)) used dynamic sizing: `risk_amount = portfolio_equity * risk_pct`.
   - On a $100,000 demo equity account with 1% risk per trade ($1,000 risk) and a tight 0.5%–1.0% stop-loss distance, theoretical position notional equaled `$1,000 / 0.005 = $200,000 Notional`.
   - Because `max_position_exposure` was set to $50,000–$100,000 VST, the risk engine capped and permitted these massive $50,000–$100,000 position sizes.
3. **Resolution in Current Regimen (Trades 601–657)**:
   - When settings/environment configuration was updated to enforce `MAX_POSITION_EXPOSURE=1000` (max $1,000 position exposure), average position size dropped to **$55.18 Notional** (max $1,000.58), reducing platform net loss across 57 trades to just **-$8.07 VST**.
