# تعیین تکلیف نهایی EPIC-01

این تصمیم اجرای دستور صریح شماست: مورد ناتمام یا تحویل شود یا از فهرست خارج شود.
از ۲۲ مورد قبلاً نپذیرفته‌شده، **۱ مورد واقعاً تکمیل شد و ۲۱ مورد با ثبتِ عدم تحویل از
دامنهٔ این EPIC خارج شد**. نتیجهٔ جاری: **۹ تحویل پذیرفته‌شده، ۲۱ حذف از دامنه، صفر صف باز**.
وضعیت EPIC: `CLOSED_PARTIAL_DELIVERY`؛ محصول کامل Trading V1 تحویل نشده و انتشار `NO-GO` است.

## مورد تکمیل‌شده

`T01-S04` — تعیین صلاحیت فایل‌به‌فایل انجام شد، نه صرف تغییر برچسب جدول:

- هش واقعی ۵۱۵۰ فایلِ inventory قبلی، شش فایل C06 و دو فایل مشاهده‌شدهٔ تازه خوانده شد.
- هر ۵۱۵۸ هش با شاهد مبنا تطبیق داشت.
- ۵۱۵۰ ورودی به‌دلیل نبود زنجیرهٔ منبع/شاهد partition مستقل، unqualified هستند.
- هشت ورودی فقط development هستند؛ هیچ فایل برای validation یا holdout مستقل پذیرفته نشد.
- نتیجهٔ طبقه‌بندی کامل است؛ نتیجهٔ صلاحیت مثبت داده، baseline یا Edge نیست.
- این تحویل جداگانه در کامیت `ed87642` ثبت شد؛ لغو دامنه جایگزین آن نشده است.
- هیچ قیمت/بازده/نتیجهٔ استراتژی تحلیل و هیچ فایل داده‌ای تغییر داده نشد.

## معنی خروج از دامنه

این ۲۱ مورد به صف تازه، backlog پنهان یا «بعداً انجام می‌شود» منتقل نشده‌اند؛ تعهد تحویلشان
در این EPIC لغو شده است. هیچ‌یک PASS، رفع خطا یا آمادگی محصول نام نگرفته‌اند. نام، وضعیت
قبلی، شاهد، دلیل لغو و وضعیت نهایی هر ۳۰ شناسه در
[رکورد کامل تصمیم](evidence/EPIC01_SCOPE_CLOSEOUT.json) و تاریخ Git حفظ شده است.
شناسه‌های قدیمی بدون دستور جدید به صف فعال برنمی‌گردند.

این تصمیم دستور قبلیِ مستقل شما برای کار محدود دادهٔ مشاهده‌شده، مدل maker و آزمایش
توسعه‌ایِ واجد شرایط را لغو نمی‌کند. قرارداد موجود آن کار حفظ می‌شود؛ آن جزء پژوهشی
جایگزین موفقیتِ baseline کامل سه پلن یا ۲۱ تعهد لغوشده نیست. بک‌لاگ تازه‌ای ساخته نشد.

## چه چیزی با حذف از فهرست حل نشده است؟

عدم‌قطعیت سفارش حفاظتی TRX، نبود شاهد جاری حفاظت/رانر، صلاحیت مستقل OOS و اثبات Edge
حل نشده‌اند. شرط‌های ایمنی در پروندهٔ P0 و کد باقی‌اند؛ پیش از شروع یا انتشار باید واقعاً
رعایت شوند. حذف تعهدِ گواهی از EPIC به معنی حذف گیت شروع، پاک‌کردن UNKNOWN یا مجوز
استقرار، سفارش، ریست حساب و پول واقعی نیست.

## کنترل پایان کار

هر ۳۰ شناسهٔ اصلی دقیقاً یک وضعیت نهایی دارد؛ یک BLOCKED با تحویل واقعی به PASS تبدیل شد؛
۲۰ BLOCKED دیگر و یک FAIL با ثبت عدم تحویل حذف از دامنه شدند. هشت PASS قبلی حفظ شدند.
معیارهای علمی R01–R26، ژورنال، cohortهای frozen و فایل‌های پژوهشی قبلی تغییر نکرده‌اند.
کنترل نگاشت/شمارش هر ۳۰ شناسه، پیوندها، هش artifact و ۵۱۵۸ تصمیم ورودی PASS شد؛
هش ۱۴۶۷ فایل محافظت‌شده و متن رجیستری R01–R26 بدون تغییر ماند. موارد هش نامنطبق،
فایل غایب و دادهٔ قبلاً دیده‌شده نیز در auditor کنترل شدند و هیچ‌کدام مجوز OOS نگرفتند.
تست تازهٔ رانر یا مرور مستقل ادعا نشده است؛ کد استراتژی، ریسک و اجرا تغییر نکرد.
