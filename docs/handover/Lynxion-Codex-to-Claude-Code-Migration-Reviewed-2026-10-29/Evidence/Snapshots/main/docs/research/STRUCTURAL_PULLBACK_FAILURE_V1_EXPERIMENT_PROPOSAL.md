## 1. Population and point-in-time eligibility

Population is **every distinct** frozen-V1 M15 candidate in a separately identified, previously untouched, source-qualified cohort; keep both directions, same-time and same-symbol overlaps and failed-looking setups. Decision time T is the close/availability time of the trigger bar, never its pivot's original time. A symbol is eligible only if contemporaneous venue metadata proves the perpetual contract was listed/tradable at T and the bar/quote/cost records pass the same predeclared checks for candidates and controls. The present six-symbol C06 panel is a selected historical cohort, not an exchange-wide point-in-time universe. Report unavailable universe metadata; never substitute today's symbol list. No V1 parameter or cohort rule may change after outcomes open.

Development-only exclusions: all C06 candidate-generation observations; all previously outcome-opened C09/C15 and Phase3A regions; AAVEUSDT/H1 and SOLUSDT/WLDUSDT M15 screenshot-associated archives until independently bounded by pre-outcome metadata. If intervals cannot be bounded, exclude the full corresponding local symbol/timeframe archive from confirmatory claims. Pilot-1 and Pilot-2 remain separate PARTIAL measurement cohorts and are not pooled, rescued or silently treated as this experiment's outcome data.

## 2. Proposed outcome, horizon and execution realism

The primary **proposed** estimand is the paired difference in mean direction-adjusted **after-cost** return, candidate minus each baseline, over four completed M15 bars (60 minutes) from T. Use the first independently timestamped marketable top-of-book quote strictly after T as the entry reference and the first such quote at/after T+60 minutes as the exit reference, with long entry at ask/exit at bid and short entry at bid/exit at ask. This requires point-in-time bid/ask depth and quote availability; next-candle open is at most a PROXY and cannot establish an executable result. Quote-to-fill latency and market impact/slippage require contemporaneous execution evidence or a conservative, frozen bound. No broker or order action is authorized by this design. The exact four-bar horizon and quote/fill convention are proposed scientific choices to freeze in a later operator-approved preregistration, not conclusions drawn from outcomes.

Apply taker fees on both sides using a documented point-in-time venue/tier schedule, spread through bid/ask prices, conservative adverse slippage/impact and any funding crossing the holding interval. Do not assume zero fees, spread, slippage or funding when unavailable. If any required cost/quote input is missing, mark the event and its matched controls `COST_UNAVAILABLE` and exclude the entire matched set by a predeclared symmetric rule; report attrition. Do not relabel modeled costs as OBSERVED. Outcome formula and units, quote freshness, impact model and fee tier must be frozen before any outcome inspection. Structural invalidation does not guarantee a stop could execute at that price.

## 3. Two nontrivial baselines

**Baseline A, primary comparator:** for each candidate at T, select a non-V1 M15 decision time in the *same symbol, direction, UTC day and four-hour time-of-day block* where the same causally confirmed prior higher-high/higher-low or lower-high/lower-low structure is present, but the full pullback-failure condition is absent. Compute eligibility using only bars closed by that baseline time. From the eligible set, take one timestamp by a preregistered deterministic hash/seed, never by future return. This tests whether V1 adds information beyond trend alignment. Any unmatched candidate is reported; no fallback to weaker trend rules.

**Baseline B, timing/context comparator:** select one non-V1 M15 timestamp from the same symbol, direction, UTC day and four-hour block without requiring the V1 structural condition. Match on a predeclared volatility/participation stratum computed only from preceding closed bars if that field can be qualified; otherwise omit it from **all** arms. Freeze seed and algorithm before outcome inspection. Do not permit either baseline to reuse a V1 event timestamp. If either baseline lacks a valid match, the complete candidate/control triplet is excluded from the paired primary analysis and attrition is reported. Baseline B is a timing control; Baseline A is the scientifically demanding comparator.

## 4. Inference and decision rule

Primary family is two pooled candidate-minus-baseline comparisons (A and B); bullish/bearish and per-symbol analyses are descriptive/exploratory unless separately preregistered and multiplicity-controlled. Preserve candidate clustering rather than treating 143 rows as independent. Resample complete UTC-day blocks with all symbols/candidates/controls together, using a frozen random seed and 10,000 block-bootstrap replicates; report raw candidate N, unique UTC days, symbol-days, cluster-size distribution and bootstrap uncertainty. For conservative planning, treat unique UTC-day blocks as the independence-unit count and separately report an outcome-blind design-effect estimate `N / (1 + (mean_cluster_size - 1) * assumed_ICC)` using an ICC justified from an external/prior source before unsealing; do not estimate that ICC from this cohort's future outcomes to rescue power. A temporal-block sensitivity analysis (whole UTC weeks) must be predeclared if multi-day dependence is material. Apply Holm family-wise 0.05 correction to the two primary comparisons. No p50/p95-like summary can substitute for uncertainty or effective-sample assessment.

Feasibility gate proposed before unsealing: at least 60 distinct UTC days, 12 UTC-week blocks, 200 matched triplets, adequate two-sided quote/fee/funding/slippage coverage, and an outcome-blind externally justified power calculation for a prespecified minimum economically meaningful incremental effect. These conservative counts are design guardrails, not a claim of sufficient power by themselves. If cluster-aware power or cost uncertainty cannot be established without peeking at outcomes, stop `DATA_LIMITED`. Acceptance proposal: after-cost candidate mean > 0 and Holm-adjusted cluster-bootstrap lower confidence bounds for incremental difference > 0 versus **both** baselines, with the preregistered minimum economic effect and all feasibility gates satisfied. Rejection proposal: sufficiently precise, adequately powered upper bounds rule out the preregistered minimum improvement; otherwise report `INCONCLUSIVE`, never rescue by changing horizon, threshold, baseline or exclusions.
